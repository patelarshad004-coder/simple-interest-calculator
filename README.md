# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates the simple interest earned or payable on a principal amount over a specified period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Example
- Principal: 1000
- Annual Interest Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

**Simple Interest: 100**

## Features
- Calculates simple interest using principal, rate, and time.
- Provides a quick and easy interest calculation.
- Suitable for basic financial calculations.
